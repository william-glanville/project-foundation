# Code Formatting Rules

- Preserve semantic units and optimize for scanning.
- Keep assignments, simple calls, parameter lists, returns, and concatenations together where practical.
- Expand meaningful logical clauses, constructors, pipelines, objects, and component hierarchies.
- Keep opening delimiters with initiating statements where tooling permits.
- Use blank lines between concepts, not related statements.
- Respect repository tooling and avoid unrelated reformatting.
- SQL requires a separate standard.
