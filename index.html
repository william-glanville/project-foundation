Welcome

The Project Foundation Framework is a reusable, technology-neutral starting point for projects where agents perform substantial analysis, design, implementation, validation, and documentation work.

Repository-resident authority, state, vocabulary, contracts, agents, skills, security gates, and validation rules reduce drift without replacing human decisions.

Framework Overview

A governed lifecycle coordinates specialist agents and reusable skills from initial repository evidence through validated reporting. Security is a mandatory gate; authority and evidence remain visible throughout.

“A well-governed project is not just built. It remains understandable, reviewable, and safe to extend.”
